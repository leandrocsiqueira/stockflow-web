# StockFlow Web

Frontend application for the StockFlow inventory management API.

Built with React, TypeScript and Vite, this project provides the web interface for interacting with StockFlow features and inventory data.

## Tech Stack

React
TypeScript
Vite
ESLint

## Backend API

This frontend consumes the StockFlow REST API:

https://github.com/leandrocsiqueira/stockflow

## Running locally

```bash
npm install
npm run dev
```

The application will start using the Vite development server.
